## 人工验收数据准备

真实 Safari 人工测试可使用现有 active Owner 账号生成一篇新的、不含图片的法律样稿：

```bash
export ACCEPTANCE_OWNER_EMAIL="<现有 Owner 邮箱>"
read -s "ACCEPTANCE_OWNER_PASSWORD?Owner password: "
export ACCEPTANCE_OWNER_PASSWORD
ACCEPTANCE_SCOPE=safari pnpm acceptance:seed
```

脚本通过正常登录和文章 API 新建带运行标识的验收文章；登录服务会拒绝非 active 账号，脚本再核验返回用户确为 Owner。它不直连或绕过 API 写数据库，不会修改密码，也不会覆盖旧文章；正常登录会更新该账号的登录时间、会话和审计记录，因此必须输入正确密码以避免触发失败计数。脚本会应用两套已安装主题，并对每套主题分别预检 `standard` 与 `wechat_safe` Renderer 及 Copy Payload，随后输出 `editorUrl`。这一结果只说明复制 payload 已生成，不表示真实 Safari 已写入剪贴板，也不会留下“复制成功”记录；必须继续人工点击、粘贴并记录结果。

`ACCEPTANCE_SCOPE=wechat` 当前只执行 `S3_PUBLIC_ENDPOINT` 公网 HTTPS 安全前置检查，四篇含图样稿的资源上传与文章准备尚未实现，并会在写入数据前明确失败。不得据此关闭微信公众号后台人工验收；完整执行仍需公网 HTTPS 图片资源和实现后的四篇含图准备流程。详细步骤见 `wechat-manual-test-record.md`。
