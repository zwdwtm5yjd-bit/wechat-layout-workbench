## 人工验收数据准备

脚本始终通过正常登录、资源、文章、文档、主题、Renderer 和 Copy Payload API 工作，不直连
数据库，不修改 Owner 密码，也不覆盖旧文章。正常登录会更新登录时间、会话和审计记录；请
使用正确的 active Owner 凭据，避免错误尝试累计。失败不会自动删除已经完成的资源或文章，
可通过输出的 `runLabel` 识别本次结果。

### Safari

```bash
export ACCEPTANCE_OWNER_EMAIL="<现有 active Owner 邮箱>"
read -s "ACCEPTANCE_OWNER_PASSWORD?Owner password: "
export ACCEPTANCE_OWNER_PASSWORD
ACCEPTANCE_SCOPE=safari pnpm acceptance:seed
unset ACCEPTANCE_OWNER_PASSWORD
```

成功结果固定为一篇无图法律样稿、两套官方主题（高级极简、现代政务红）、2 次主题应用和
4 个“主题 × `standard` / `wechat_safe`”输出及 Copy Payload。结果只表示正式 Payload 已生成，
不表示真实 Safari 已写入剪贴板；仍须打开 `editorUrl` 点击复制并人工记录。

### 微信公众号含图验收

运行中的 API 与 seed 进程必须使用同一个公网 HTTPS `S3_PUBLIC_ENDPOINT`。Docker Compose
现在允许从宿主环境覆盖本地默认值；若使用本仓库 Compose，应先用该变量重建或重启 API：

```bash
export S3_PUBLIC_ENDPOINT="https://<公网对象存储地址>"
pnpm docker:dev

export ACCEPTANCE_OWNER_EMAIL="<现有 active Owner 邮箱>"
read -s "ACCEPTANCE_OWNER_PASSWORD?Owner password: "
export ACCEPTANCE_OWNER_PASSWORD
ACCEPTANCE_SCOPE=wechat pnpm acceptance:seed
unset ACCEPTANCE_OWNER_PASSWORD
```

若连接的是已经正确配置的远程环境，无需运行 `pnpm docker:dev`，但应设置对应的
`ACCEPTANCE_API_BASE_URL` 和 `ACCEPTANCE_WEB_BASE_URL`。远程地址只允许 HTTPS。

wechat scope 会在登录和任何写入前检查 Endpoint 为 HTTPS、DNS 仅解析到公网地址、当前执行机
可访问且不发生重定向或 5xx；随后上传或去重 52 张确定性 PNG，保存四篇固定样稿，应用两套
固定主题并生成 16 个正式输出。脚本还会确认 API 返回的签名 URL 与本次 Endpoint 一致，并从
当前执行机逐一 GET 52 个实际 Copy Payload 图片对象，要求 `2xx + image/*`。成功计数必须为：

```text
文章 = 4
图片 = 党政巡察 1 + 法律 0 + AI 科技 1 + 极端 50 = 52
resources.uploaded + resources.deduplicated = 52
themeApplications = 8
renderOutputs = 16
publicImageObjectsVerified = 52
copyRecordWritten = false
published = false
```

这些检查仍不能证明微信服务器自身可以抓取图片，也不能代替浏览器剪贴板、公众号后台粘贴、
手机预览和保存草稿。Copy Payload 有效期为 15 分钟，生成后应尽快人工验收。详细记录模板见
[`wechat-manual-test-record.md`](./wechat-manual-test-record.md)。

## 公网生产上线的额外门槛

V0.1 功能标签不等于公网生产系统已经可部署。当前仓库的 Compose 和 Node 镜像仍以开发运行
方式为主；正式公网部署还需完成并演练：

1. 生产镜像、生产 Compose 或目标云平台运行清单，以及明确的发布/回滚流程；
2. 域名、TLS、反向代理、生产数据库/Redis/对象存储/SMTP 和全部 Secret 注入；
3. 上线前备份、维护窗口内迁移、恢复演练与回滚验证；`0004` 回填期间必须停止旧版本写入；
4. 日志、指标、告警、备份巡检和容量限制；
5. 在与生产等价的预发布环境重新执行本清单。
