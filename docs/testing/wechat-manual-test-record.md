## 判定标准

- 所有样稿可粘贴并进入微信后台预览；
- 原文没有缺字、改字或乱序；
- 不包含脚本、编辑器类名、`contenteditable` 或危险链接；
- 严重兼容问题必须在复制前阻断；
- Safari 无法写入富文本剪贴板时，手动复制兜底必须可用；
- “复制成功”只表示写入剪贴板，不得声称已经发布。
