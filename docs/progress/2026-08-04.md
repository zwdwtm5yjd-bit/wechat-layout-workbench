# 2026-08-04 开发记录

## 今日任务

`S2-IMPORT-002 网页导入`

## 完成内容

- 新增 `POST /api/v1/imports/webpage`，在 Owner 事务内创建待导入文章、来源文档、审计记录
  和权威 `import-webpage` 任务；投递失败会回写失败状态；
- 新增安全 HTTP 抓取包：只接受无凭据 HTTP(S) URL，拦截 localhost、私网、链路本地、
  保留/文档/测试网段和混合公网/私网 DNS 答案，每次重定向重新解析并校验；连接固定到已
  校验地址，避免 DNS rebinding；
- 支持 gzip、deflate、Brotli 解压、超时、响应大小、内容类型、重定向次数和取消边界；
- 使用 Mozilla Readability 和 JSDOM 提取正文，删除脚本、广告、隐藏节点、事件属性、危险
  URL 和冗余样式，生成稳定 Source Blocks、清洗统计与抓取警告；
- HTTP 结果正文不足或疑似 JS Shell 时回退到独立 Playwright Chromium 服务；浏览器服务
  通过安全 HTTP/CONNECT 代理对每个子资源重新校验，并禁止媒体、字体、下载和 Service
  Worker；
- 浏览器容器不注入数据库、Redis、S3 凭据，只连接 Worker 控制网和独立出网；生产制品以
  `node` 用户、只读根文件系统、`cap_drop: ALL` 和 `no-new-privileges` 运行；
- Worker 下载正文图片时复用 SSRF 边界，仅接受通过文件魔数确认的 PNG、JPEG、GIF、WebP，
  私有化存储资源后生成 Document V1；SVG、可执行内容、超限或失败图片只产生警告；
- 私有保存 Webpage Intermediate v1，并在来源元数据记录请求 URL、最终 URL、重定向链、
  抓取策略、解析器、哈希、统计、警告和图片失败；原 URL 保持不可变；
- 修复 Node 24 `lookup({ all: true })` 下固定 DNS 回调必须返回地址数组的问题，并将只读
  Chromium 的 HOME 固化到 `/tmp`；生产模板测试夹具改在 Docker 可共享的工作区 `tmp/`
  创建一次性 TLS 证书。
