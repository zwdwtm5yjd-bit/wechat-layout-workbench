`S1-RENDER-001 微信 HTML Renderer 核心`

## 完成内容

- 实现 `@wechat-layout/wechat-renderer` 服务端渲染包，从通过校验的 Document Schema V1
  JSON 生成微信正文 HTML，不依赖编辑器 DOM；
- 建立可冻结的 Node Renderer 和 Component Renderer 注册表，拒绝重复注册及冻结后修改；
- 覆盖段落、三级标题、引用、无序列表、有序列表、图片、分割线、语义卡片、品牌页脚和
  SVG 互动占位共 11 类 Block Renderer；
- 接入 Token Engine，按标准、安全和静态模式解析系统、主题、品牌、组件与节点局部样式；
- 接入 Component Registry，按文档固化的 `componentId@version` 精确读取 Manifest，
  再调用声明的内置 `wechatRendererKey`；
- 建立安全 HTML AST，不开放 Raw HTML；集中执行标签、属性、URL 和 CSS 白名单序列化；
- 将所有样式内联，确定性排序属性和声明，并转义正文、属性及组件内容；
- 图片和链接只接受不含凭据、不指向本机或私网的公网 HTTPS URL；
- 缺失或非法图片生成可读占位，缺失或停用组件使用保留原文的安全结构；
- 标准模式保留受控视觉样式，安全模式移除复杂背景、阴影和风险定位，静态模式继承安全
  规则并转换互动内容；
- SVG 安全引擎尚未进入本阶段，因此所有模式暂使用文档中的静态备用图并返回明确提示；
- 输出 Renderer `1.0.0` 版本、HTML SHA-256、原文哈希、资源 ID、组件精确版本和文档
  Schema 版本 Manifest；
- 增加无效文档、原文哈希不匹配、Token 错误、嵌套降级和缺失 Renderer 的结构化失败；
- 新增包级 README，并更新根 README 的开发状态和下一任务。

## 技术决策

- Renderer 只消费权威文档 JSON；编辑器 DOM、Node View、Class 和交互控件不进入输出路径；
- HTML 只能由类型化安全 AST 构造，组件 Renderer 也不能返回任意 HTML 字符串；
- `standard`、`wechat_safe`、`static` 使用同一节点语义，仅由 Token 和样式策略执行可比较
  降级；
- 安全模式禁止 `background` 简写、背景图和阴影，只允许 `position: static`；标准模式也
  禁止 `fixed` 与 `sticky`；
- URL 清洗不负责网络请求，仅建立最终输出边界；资源获取、签名和公开地址生成继续由资源
  服务负责；
- 有序列表保留原编号时关闭浏览器原生编号，避免微信粘贴后出现重复编号；
- SVG 动态执行不提前实现，当前强制静态备用图，等待 `S2-SVG-001` 的协议与安全引擎；
- 兼容评分、问题规则版本和自动修复不并入本任务，留给紧随其后的 `S1-COMPAT-001`。
