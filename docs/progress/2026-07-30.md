## 技术决策

- `APP_ENV` 表示应用配置环境，生产构建和运行必须显式设置；服务端同时校验其与 `NODE_ENV` 一致；
- 配置文件优先级为 `.env`、`.env.<环境>`、本机覆盖文件、进程环境变量；
- 测试环境跳过 `.env.local`，避免开发机配置污染测试；
- 默认包入口保持浏览器安全，服务端代码必须显式导入 `@wechat-layout/config/server`；
- Secret 只有在业务适配器明确调用 `revealSecret` 时才能取得明文，普通日志和序列化默认脱敏；
- 微信凭据仍按公众号连接记录加密保存，本任务不把真实微信 AppSecret 作为全局开发环境变量；
- 本任务不提前实现健康路由、OpenAPI、数据库 Schema 或业务接口。

## 完成内容

- 为业务 API 配置全局 `/api/v1` 版本前缀，健康检查保持根路径；
- 创建 Request ID / Trace ID 中间件，支持安全透传或自动生成，并写入响应头；
- 使用 AsyncLocalStorage 建立请求上下文，为后续服务和审计共享追踪信息；
- 创建统一成功响应拦截器，返回 `success`、`data` 和请求元信息；
- 创建全局异常过滤器和稳定错误码映射，统一失败响应；
- 创建 class-validator DTO / Zod DTO 双模式全局校验管道，字段错误格式一致；
- 创建脱敏结构化日志拦截器，只记录请求方法、无查询路径、状态码、耗时和错误码；
- 创建 `ApiException`，供后续业务模块显式声明 HTTP 状态、错误码和可重试性；
- 创建 `/health/live` 和 `/health/ready`，并提供可注册依赖探针的 Readiness Registry；
- 集成 Swagger / OpenAPI，注册通用成功、错误和元信息 Schema；
- 非生产环境提供 `/api/docs`，所有环境提供 `/api/openapi.json`；
- 创建审计 Sink 接口与注入 Token，预留不可绕过的持久化边界；
- 将 Docker API 健康检查升级为真实 HTTP 存活检查；
- 扩展 Docker 烟测，验证 live、ready 和 OpenAPI JSON。

## 技术决策

- 使用 NestJS 官方 `@nestjs/swagger` 和 `@nestjs/terminus` 集成，不自建 OpenAPI 或健康框架；
- 健康路由标记为 Raw Response，保持基础设施探针兼容的 Terminus 格式；
- 当前就绪状态检查 API 进程与已注册探针；数据库、Redis、对象存储、Worker 心跳和迁移版本
  由后续连接层注册，避免本任务建立临时连接实现；
- 全局过滤器只向客户端返回白名单错误内容，未知 500 在任何环境都不回显异常文本；
- 日志不记录请求头、Cookie、查询参数、请求体、响应体或异常消息；
- Swagger UI 在生产环境关闭，OpenAPI JSON 保留用于后续受保护的 Client 生成流程；
- 审计接口只冻结契约，不提供静默丢弃事件的 No-op 实现。

## 发现问题

- 沙箱默认禁止 Supertest 绑定本机随机端口；授权回环监听后真实 HTTP 集成测试全部通过；
- `tsx watch` 不生成构造器反射元数据；基础设施组件改用显式 `@Inject`，保证开发容器与编译产物
  的依赖注入行为一致；
- Swagger 在 `tsx` 直接运行源码时不能可靠推断标量模型类型；OpenAPI 模型改为显式声明类型，
  避免错误识别为循环依赖；
- NestJS 11 不再接受旧式匿名 `*` 路由通配符，中间件注册改用命名通配符 `{*splat}`；
- pnpm 对 Vitest 间接 WASM 绑定仍报告原有可选 peer 警告，不影响原生绑定；
- Terminus 的数据库与外部依赖探针需要后续连接适配器，当前不提前引入 Drizzle、Redis Client
  或 S3 Client。
