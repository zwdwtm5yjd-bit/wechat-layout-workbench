# 一、设计目标

前端需要达到以下体验目标：

1. 视觉上现代、克制、专业，不像传统公众号编辑器；
2. 用户登录后可快速开始排版；
3. 编辑器三栏结构清晰，复杂但不压迫；
4. 主题、组件和SVG都以视觉方式选择；
5. 多公众号切换具备明显但不打断工作的品牌提示；
6. 兼容检查和保存状态始终可见；
7. 普通用户默认看到简化界面；
8. 高级能力在专业模式中逐步展开；
9. 长时间编辑时保持稳定、低干扰；
10. 任何错误都提供明确恢复路径。

# 二、整体视觉方向

# 2.1 产品视觉关键词

```text
现代
专业
编辑感
克制
清晰
有秩序
有设计感
不过度装饰
```

参考气质：

- Notion的结构清晰；
- Craft的编辑精致；
- Linear的操作效率；
- Framer的设计感；
- Canva的素材可视化；
- 但不复制任何产品界面。

# 2.2 基础色彩

系统UI默认采用中性浅色界面。

建议：

```text
页面背景：#F7F7F5
面板背景：#FFFFFF
主文字：#18181B
次文字：#71717A
弱文字：#A1A1AA
边框：#E4E4E7
悬浮背景：#F4F4F5
选中背景：#EEF2FF
强调色：#4F46E5
成功：#15803D
警告：#B45309
危险：#B91C1C
```

说明：

- 系统强调色与公众号品牌色分开；
- 编辑器画布中的品牌色不得影响系统按钮；
- 深色模式作为V1.0增强项；
- 首版优先把浅色模式做好。

# 2.3 字体

系统UI使用系统字体栈：

```css
-apple-system,
BlinkMacSystemFont,
"Segoe UI",
"PingFang SC",
"Hiragino Sans GB",
"Microsoft YaHei",
sans-serif
```

UI字号：

| 用途 | 字号 |
|---|---:|
| 页面大标题 | 24px |
| 页面标题 | 20px |
| 卡片标题 | 16px |
| 正文 | 14px |
| 辅助文字 | 13px |
| 标签 | 12px |
| 极小状态 | 11px |

# 2.4 圆角

系统UI：

- 大卡片：12px；
- 普通卡片：8px；
- 输入框：8px；
- 按钮：8px；
- 标签：6px；
- 胶囊状态：999px。

编辑器内公众号内容的圆角由主题控制，不使用系统UI圆角。

# 2.5 阴影

系统只使用轻阴影：

```css
0 1px 2px rgba(0,0,0,0.04)
0 8px 24px rgba(0,0,0,0.06)
```

弹窗可稍强，但不使用厚重阴影。

# 三、页面框架

# 3.1 普通后台框架

```text
┌──────────────────────────────────────────────┐
│ 左侧导航 │ 顶部栏                            │
│          ├───────────────────────────────────┤
│          │ 页面内容                          │
│          │                                   │
│          │                                   │
└──────────────────────────────────────────────┘
```

建议：

- 左侧导航收起宽度72px；
- 展开宽度224px；
- 顶部栏高度56px；
- 页面内容最大宽度1440px；
- 页面内边距24px至32px。

# 3.2 编辑器独立框架

```text
┌──────────────────────────────────────────────────────────┐
│ 顶部编辑器栏 56px                                        │
├───────────────┬───────────────────────┬──────────────────┤
│ 左侧 280px     │ 中央自适应              │ 右侧 300px        │
│               │                       │                  │
├───────────────┴───────────────────────┴──────────────────┤
│ 底部状态栏 28px                                           │
└──────────────────────────────────────────────────────────┘
```

宽屏下：

- 左侧：280px；
- 右侧：300px；
- 中央最小：620px。

1366px宽度下：

- 左侧：250px；
- 右侧：280px；
- 中央自适应。

小于1200px：

- 右侧默认抽屉；
- 左侧可折叠；
- 中央保持至少560px。

# 三十三、空状态

# 33.1 原则

空状态包含：

- 简洁插图或图标；
- 一句说明；
- 一个主操作；
- 可选次操作。

# 33.2 文章为空

> 还没有文章。导入一篇定稿内容开始排版。

# 33.3 公众号为空

> 创建公众号品牌档案后，系统才能自动应用Logo、二维码和品牌色。

# 33.4 收藏为空

> 收藏常用主题和组件，编辑时会更快。

# 33.5 更新为空

> 当前已是最新版本。

# 33.6 搜索无结果

> 没找到匹配内容。试试减少筛选条件。

# 三十四、加载状态

# 34.1 页面加载

使用骨架屏，不使用整页转圈。

# 34.2 编辑器加载

顺序：

1. 加载编辑器框架；
2. 加载文章结构；
3. 加载图片缩略图；
4. 加载SVG首帧；

```text
正在恢复编辑内容…
```

# 34.3 主题和组件

卡片使用固定比例骨架，避免布局跳动。

# 34.4 异步任务

显示明确阶段，而不是只显示百分比。

# 三十五、错误状态

# 35.1 页面级

- 404；
- 500；
- 无权限；
- 网络中断；
- 服务维护。

# 35.2 编辑器错误

编辑器加载失败：

- 从本地草稿恢复；
- 打开最近快照；
- 重新加载；
- 下载恢复数据。

# 35.3 资源错误

图片失败显示占位：

- 重新加载；
- 替换；
- 查看来源。

# 35.4 SVG错误

SVG节点失败：

- 显示静态降级；
- 重新生成；
- 更换模板；
- 删除。

# 35.5 保存错误

顶部状态保持红色，直到成功。

网络恢复后自动重试。

# 三十六、Toast与确认

# 36.1 Toast用途

适合：

- 保存成功；
- 收藏成功；
- 复制成功；
- 轻量错误；
- 操作撤销。

不适合：

- 严重兼容问题；
- 删除公众号；
- 草稿覆盖；
- 数据恢复。

# 36.2 Toast位置

右下角，最多同时3条。

# 36.3 撤销Toast

例如：

> 已删除组件  
> 撤销

持续6至8秒。

# 36.4 确认弹窗

高风险操作必须说明：

- 会发生什么；
- 会影响什么；
- 是否可恢复；
- 下一步。

# 四十二、交互验收标准

# 42.1 工作台

- 10秒内可发起新建；
- 最近文章可一键打开；
- 当前公众号和更新状态清楚；
- 页面不显拥挤。

# 42.2 编辑器

- 三栏可调整；
- 画布始终为视觉中心；
- 选中区块反馈明确；
- 原文锁定状态明显；
- 自动保存状态清楚；
- 主题试穿不立即覆盖；
- 组件插入路径不超过3步；
- SVG模板插入路径不超过5步。

# 42.3 兼容

- 问题可定位；
- 可区分严重、警告和建议；
- 自动修复先预览；
- 复制前状态明确。

# 42.4 多公众号

- 当前公众号始终可见；
- 切换前能看到影响；
- 已发布文章默认创建副本；
- Logo、二维码和文末不易混用。

# 42.5 异常

- 网络中断不丢文章；
- 保存失败有恢复方式；
- SVG失败有静态降级；
- 导入失败保留原文件；
- 同步失败可降级复制。

# 四十三、前端设计冻结

本文件正式冻结以下规则：

1. 普通后台采用左侧导航＋顶部栏；
2. 编辑器采用独立三栏布局；
3. 编辑器左侧280px、右侧300px为默认；
4. 公众号画布始终是视觉中心；
5. 编辑器普通模式默认隐藏高级参数；
6. 主题先试穿再应用；
7. 组件支持拖入和点击插入；
8. SVG中心按用途而不是技术分类；
9. SVG向导必须同时显示动态与静态降级；
10. 多公众号切换必须显示变化和冲突；
11. 保存、兼容和公众号状态必须始终可见；
12. 页面加载优先骨架屏；
13. 异步任务显示阶段和进度；
14. 严重操作使用明确确认弹窗；
15. 手机端不承担完整编辑；
16. 所有核心操作必须支持键盘；
17. 系统色与公众号品牌色分离；
18. 深色模式不是V0.1阻塞项；
19. 任何单个组件错误不得导致整篇文章无法编辑；
20. 后续前端开发和视觉稿均以本规范为准。
